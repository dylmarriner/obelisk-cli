:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Obelisk ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-obelisk](https://github.com/awesome-obelisk/awesome-obelisk) และ [obelisk.cafe](https://obelisk.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
